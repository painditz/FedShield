Central Orchestration Server

The FedShield Server coordinates global communication rounds ($T$). Byzantine Adversarial Poisoning & Defense Lab

In distributed systems, malicious edge nodes can transmit poisoned parameter updates to steer global convergence away from the optimal point. Below is empirical verification of how Coordinate Median and Trimmed Mean filter out adversarial updates and restore classification performance.

Sign-Flipping Attack

Inverts the parameter update: $\Delta w_{adv} = -s \cdot (w_k - w_{global})$. Naive FedAvg averages this opposite direction, dropping accuracy to 11.4%.

Coordinate Median Defense

Takes the median value coordinate-by-coordinate across all clients. Extreme outliers and inverted updates cannot shift the median, recovering accuracy to 28.4%.

Trimmed Mean Defense

Sorts coordinates across clients and trims the top and bottom $\beta$ fraction (e.g. 20%) before computing the mean. Effectively discards all poisoned coordinates.

Non-IID Statistical Heterogeneity Simulator

Client datasets in real-world federated learning are Non-IID. FedShield partitions CIFAR-10 classes using Dirichlet distributions: $p_{c} \sim \text{Dir}(\alpha)$. Lower $\alpha$ values create severe class imbalances where clients hold only 1-2 dominant classes.

Differential Privacy (DP) & Privacy-Utility Tradeoff

To prevent model inversion and training data extraction attacks, FedShield enforces $(\epsilon, \delta)$-Differential Privacy via the Subsampled Gaussian Mechanism with $L_2$ update clipping and analytical Moments Accountant tracking.
